# Video Game Sales Prediction Using Machine Learning

## Project Overview
This project aims to predict global video game sales using historical sales data and machine learning techniques.

## Academic Project
- Course: BCA
- Project: PBL Project 2

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithms
1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor

## Project Methodology
1. Dataset Understanding
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Data Preprocessing
6. Training and Testing
7. Model Evaluation
8. Five-fold Cross-validation
9. Hyperparameter Tuning
10. Confusion Matrix Analysis
11. Final Model Selection

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Files
- `Video_Game_Sales_Prediction.ipynb` — Complete machine learning notebook.
- `vgsales.csv` — Original dataset.
- `Video_Game_Sales_Project_Results.zip` — Project results.

## How to Run
1. Download the notebook and dataset.
2. Open the notebook in Google Colab.
3. Upload the dataset.
4. Select Runtime → Run all.

## Conclusion
This project compares three regression algorithms to identify a suitable machine learning model for predicting global video game sales.
